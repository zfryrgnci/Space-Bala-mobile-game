## 🎮 About The Game

**Space Bala** is a tribute to the legendary Nokia mobile games of the early 2000s, specifically inspired by *Space Impact*. It ditches modern complex 3D physics in favor of pure, addictive, and responsive 2D arcade gameplay. 

The game features a strict retro aesthetic, a synthwave color palette, and a fully functional 5-level progression system that introduces new enemy mechanics as your score increases, culminating in a massive Boss Fight!

---

## 🕹️ Features & Level Progression

- **Pure HTML5 Canvas**: Zero heavy dependencies, perfectly optimized 60FPS rendering.
- **Level 1 (Basic)**: Red interceptor ships moving straight left.
- **Level 2 (Fast Interceptors)**: Tiny, high-speed yellow ships.
- **Level 3 (Asteroid Fields)**: Massive, slow-moving gray asteroids with high HP that act as moving walls.
- **Level 4 (Wave Ships)**: Unpredictable purple ships moving in a sine-wave pattern.
- **Level 5 (Mothership Boss)**: At 1,000 points, the screen clears and a massive Boss Ship appears, firing 3-way spread lasers.
- **Ad-Ready**: Includes a native Game Over UI overlay designed for AdSense integration.

---

## 💻 Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5 Canvas 2D API, CSS3.
- **Collision Detection**: Axis-Aligned Bounding Box (AABB) physics.
- **Distribution**: Available as a Progressive Web App (PWA) and easily wrappable into a native Android APK via WebView.
